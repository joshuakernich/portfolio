LV 08

Star Crew

A real-time space adventure where each player runs their own station on the bridge.

The game

Star Crew is a digitally enhanced game room for two to six players. Each player takes one of six roles on a spaceship and runs a touch console built on MIDI hardware. Crews talk to each other through a microphone-controlled audio system as they fly a real-time space adventure together.

What I did

  • Designed the interactive game and the six crew roles
  • Designed the touch interfaces built on MIDI hardware
  • Designed how the crew communicates through microphones
